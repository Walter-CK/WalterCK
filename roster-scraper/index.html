Roster Scraper

Logs into McDonald's Australia's myRestaurant portal, reads your published roster, and turns it into a plain JSON feed — so a phone automation can set your shift alarms without you opening the app.

Get the Shortcut Source on GitHub Python + Playwright

Why this exists

myRestaurant doesn't have an API, a calendar export, or a way to get notified when a new roster's published. If you want your shifts anywhere else — a Shortcuts automation, a calendar, an alarm — you're stuck opening the app and reading it yourself, every week.

This script does that reading for you: it drives a real browser through the actual login flow (McDonald's uses Microsoft SSO, so there's no simple form-post shortcut here), pulls the roster page's HTML once you're in, and parses out every shift into structured JSON.

Setting it up

  1. Get the files

    Clone or download the repo, then open a terminal in that folder.

    git clone https://github.com/Walter-CK/WalterCK.git
cd WalterCK/roster-scraper

  2. Install Python

    You need Python 3.10 or newer. If python --version in a terminal doesn't show that, grab it from python.org — on Windows, tick "Add Python to PATH" during install.

  3. Install the dependencies

    pip install -r requirements.txt
playwright install chromium

    The second command downloads the actual browser Playwright drives — it's a one-time download, separate from any browser you already have installed.

  4. Add your login

    Open .env in any text editor and fill in your myRestaurant credentials — the same archID and password you use to log in normally.

    MYJOB_USERNAME=your.username@crew.mcd.com
MYJOB_PASSWORD=your-password
    This file never leaves your machine. It's listed in .gitignore, so a normal git push won't include it. Don't paste your real credentials anywhere else — not into an issue, a message, or a screenshot.

  5. Run it

    python scrape_roster.py

    First run, open scrape_roster.py and set HEADLESS = False near the top — this pops up a visible browser window so you can watch the login happen and confirm it's working, rather than running invisibly. Once you've seen it succeed once, switch it back to True for normal use.

    A successful run ends with a line like Wrote 7 shifts across 2 week(s) to roster.json. If it fails partway through, it saves a screenshot and the page's HTML next to the script so you can see exactly what it was looking at when it broke.

What comes out

Every run produces a fresh roster.json, shifts grouped by the roster's own weekly periods:

{
  "last_updated": "2026-09-25T09:25:00+10:00",
  "weeks": [
    {
      "week_start": "21/09/26",
      "week_end": "27/09/26",
      "shifts": [
        {
          "date": "23/09/26",
          "start": "1:00 PM",
          "end": "4:00 PM",
          "location": "BERRINBA QLD",
          "hours": "3:00"
        }
      ]
    }
  ]
}

hours is a duration, not a decimal — "3:15" means 3 hours 15 minutes, not 3.15 hours.

Getting it onto your phone

The script runs on a computer, but the point is having your shifts on your phone without opening anything. The way I've got it wired up:

Push to GitHub after each run

The script commits and pushes roster.json automatically if it changed, so the latest roster is always sitting in the repo — no manual upload step.

Run it on a schedule

Windows Task Scheduler (or cron on Mac/Linux) runs the script daily, so a newly published roster shows up without you doing anything.

Pull it into a Shortcut

An iOS Shortcut fetches roster.json straight from GitHub, reads through each week and shift, and sets an alarm ahead of each one. Private repo? The Shortcut authenticates with a fine-grained token scoped to read-only access on just this repo.

What the Shortcut actually does

The Shortcut is the other half of this system — it reads roster.json and turns it into something you actually look at, without opening the myRestaurant app.

  1. Pulls your latest roster

    Fetches roster.json straight from GitHub and groups your shifts into This Week and Next Week, showing the day, start time and end time for each one.

  2. Sets alarms ahead of each shift

    Choose Create/Change Alarms, tell it how many minutes before a shift you want waking up, and it adds one alarm per upcoming shift automatically — no manually doing the maths on start times every week.

  3. Keeps your alarms in sync

    Run it again after a new roster's published and it clears out the old shift alarms before creating the new ones, so you're never left with a stale alarm for a shift that got moved or dropped.

  4. Triggers a fresh scrape on demand

    Choose Re-scan shifts and the Shortcut asks GitHub to run the scraper again right away, instead of waiting for the next scheduled run — handy the moment a new roster gets published.

This is a template, not a plug-and-play app. The Shortcut is wired to my GitHub repo and my roster's JSON shape — using it yourself means pointing it at your own roster.json (and running your own copy of the scraper, or one adapted to your employer's portal). It's shared as a working example to adapt, not a one-tap install.
Heads up if you're adapting this yourself: myRestaurant's login flow is McDonald's own enterprise Microsoft SSO setup, not a simple username/password form — expect to spend time in the script's selectors if your restaurant's portal renders slightly differently, or if Microsoft/McDonald's change the page layout later. The script logs each step as it goes, which makes it easier to see exactly where a run stalls.
